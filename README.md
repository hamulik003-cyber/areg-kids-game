# Արեգ 3D աշխարհ

Full-screen mobile/PWA home screen rebuilt from the supplied 709×1536 master blueprint.

## Run locally
Use any static web server, for example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080/`.

## GitHub Pages
Upload the **contents** of this folder to the repository `main` branch, then enable GitHub Pages from the root of `main` if it is not already enabled.
