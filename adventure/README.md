# AREG Six Worlds — isolated development module

Status: M0 scaffold, NOT a playable or completed game.

Source: AREG MASTER PROMPT v2.0 (48 sections, 6 worlds).

This directory is isolated from the existing AREG Kids Game. Do not modify main, existing games, service worker, star economy or production navigation without a separate approved integration.

## Acceptance
